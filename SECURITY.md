# Security policy

Report vulnerabilities privately through the repository's **Security** tab (**Report a vulnerability**), not in a public issue. Include how to reproduce and the affected versions. We acknowledge within 5 working days and fix confirmed issues within 30 days.

In scope: the module `github.com/entur/go-mcpkit`, its workflows and release process. Only the latest release is supported; a bad release is fixed forward and retracted in `go.mod`, and tags are never moved or deleted.
