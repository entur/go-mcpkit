# go-mcpkit

Shared Go library for Entur's [Model Context Protocol](https://modelcontextprotocol.io) (MCP) servers.

**Status:** pre-release, no API yet; v0.1.0 is planned.

```sh
go get github.com/entur/go-mcpkit # Go 1.26 or later
```
